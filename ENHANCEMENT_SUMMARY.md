## 🚀 How to Use

### Test It Now!
1. Compile: `npm run compile`
2. Press **F5** to debug
3. Open a work item
4. Try the new features:
   - Select text → Choose heading from dropdown
   - Click color picker → Choose text color
   - Click alignment → Center your text
   - Click blockquote → Quote some text
   - Click image → Insert a screenshot
