# Azure DevOps Test Data Generator

This script creates test work items and sprints to help you test the board view with iteration filters.

## What It Creates

- **5 Sprints** with realistic date ranges:
  - Sprint 1: Past (ended 30 days ago)
  - Sprint 2: Past (ended 16 days ago)
  - Sprint 3: **Current** (started 7 days ago, ends in 7 days) ← includes today
  - Sprint 4: Future (starts in 8 days)
  - Sprint 5: Future (starts in 22 days)

- **25 Work Items** (5 per sprint):
  - 3 User Stories with description & acceptance criteria
  - 1 Bug with description
  - 1 Task with description

All items are tagged with `TestData-AutoGenerated` for easy cleanup.

## Prerequisites

1. **Azure DevOps Personal Access Token (PAT)**
   - Go to Azure DevOps → User Settings → Personal Access Tokens
   - Create a new token with **Work Items (Read, Write)** permissions
   - Copy the token (you'll need it below)

2. **Node.js** installed (the script uses built-in Node modules, no dependencies needed)

## Quick Start

### 1. Set Environment Variables

**Option A: Export in terminal (Mac/Linux)**
```bash
export ADO_ORG_URL=https://dev.azure.com/your-organization
export ADO_PROJECT=YourProject
export ADO_TEAM=YourTeam
export ADO_PAT=your-pat-token-here
```

**Option B: Export in terminal (Windows PowerShell)**
```powershell
$env:ADO_ORG_URL="https://dev.azure.com/your-organization"
$env:ADO_PROJECT="YourProject"
$env:ADO_TEAM="YourTeam"
$env:ADO_PAT="your-pat-token-here"
```

**Option C: Edit the script directly**
Open `generate-test-data.js` and update the config at the top:
```javascript
const config = {
    organizationUrl: 'https://dev.azure.com/your-organization',
    project: 'YourProject',
    team: 'YourTeam',
    pat: 'your-pat-token-here'
};
```

### 2. Create Test Data

```bash
node scripts/generate-test-data.js create
```

**Important:** The script will show you iteration paths that need to be created. You'll need to manually create them in Azure DevOps:

1. Go to **Project Settings** → **Boards** → **Project Configuration** → **Iterations**
2. Create the iteration paths shown by the script (e.g., `YourProject\Test Sprint 1`)
3. Set the start and finish dates as shown by the script
4. After creating the iterations, wait for the script to continue (or press any key)

The script will then create all 25 work items assigned to the sprints.

### 3. Test Your Board

1. Open the Azure DevOps Boards extension in VS Code
2. Navigate to the board view
3. Use the **Iteration filter** to filter by sprints
4. Use the **@CurrentIteration** checkbox to see only current sprint items
5. Verify descriptions and acceptance criteria appear correctly

### 4. Clean Up When Done

```bash
node scripts/generate-test-data.js cleanup
```

This will delete all work items tagged with `TestData-AutoGenerated`.

**Note:** Iteration paths are not automatically deleted. To remove them:
- Go to **Project Settings** → **Boards** → **Project Configuration** → **Iterations**
- Manually delete the test iteration paths

## Troubleshooting

### "Failed to create work item"
- **Check PAT permissions:** Your PAT needs Work Items (Read, Write)
- **Check PAT expiration:** Make sure your PAT hasn't expired
- **Check project/team names:** Ensure they're spelled correctly

### "Failed to create iteration"
- **Expected behavior:** The API cannot create iteration paths without admin permissions
- **Solution:** Manually create the iteration paths in Project Settings (instructions shown by script)

### "No work items found" during cleanup
- The script successfully created and cleaned up work items
- Or work items were manually deleted/tagged differently

### Authentication errors
- Verify your PAT is correct
- Check that PAT has not expired
- Ensure PAT has Work Items (Read, Write) scopes

## Script Details

### File Structure
```
scripts/
├── README.md                 # This file
└── generate-test-data.js     # Main script
```

### Key Functions
- `createIterations()` - Creates sprint structure (shows paths to create manually)
- `createWorkItems()` - Creates 25 work items with descriptions
- `findTestWorkItems()` - Finds all items with test tag
- `deleteWorkItems()` - Removes test work items
- `generateDescription()` - Creates realistic HTML descriptions
- `generateAcceptanceCriteria()` - Creates acceptance criteria for User Stories

### Tags Used
All test work items are tagged with: `TestData-AutoGenerated`

This allows the cleanup function to find and delete only the test items.

## Tips

1. **Run in a test project first** to verify the script works correctly
2. **Keep your PAT secure** - don't commit it to git
3. **Review created items** in Azure DevOps web before testing the VS Code extension
4. **Use cleanup regularly** to avoid cluttering your backlog
5. **Adjust sprint dates** in the script if you need different date ranges

## Safety Features

- All work items are tagged for easy identification
- Cleanup waits 3 seconds before deletion (time to cancel with Ctrl+C)
- Script shows exactly what will be created/deleted before proceeding
- Only deletes items with the specific test tag

## Advanced Usage

### Customize Sprint Count
Edit the `sprintSchedule` array in `createIterations()`:
```javascript
const sprintSchedule = [
    { name: 'Test Sprint 1', start: -44, end: -30 },  // Add more or modify
    // ...
];
```

### Customize Work Item Types
Edit the `WORK_ITEM_TYPES` array:
```javascript
const WORK_ITEM_TYPES = [
    { type: 'User Story', count: 3 },
    { type: 'Bug', count: 1 },
    { type: 'Task', count: 1 },
    { type: 'Epic', count: 1 },  // Add new types
];
```

### Change Test Tag
Edit the `TEST_TAG` constant:
```javascript
const TEST_TAG = 'MyCustomTag';
```
